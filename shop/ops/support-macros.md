# Support macros

Plain, fast, honest. Replace every `[BRACKET]`. Keep every reply under 120 words. Never promise what the supplier data does not support.

## 1. Where is my order?

```
Hi [FIRST NAME],

Thanks for writing. Your order [ORDER NUMBER] shipped on [DATE]. Tracking: [TRACKING LINK]. Delivery is typically [Y]-[Z] business days after shipping, so we expect it by [DATE].
If it has not moved in [N] business days, reply and we will chase it.

[NAME], [BRAND]
```

## 2. Order is late

```
Hi [FIRST NAME],

You are right: your order [ORDER NUMBER] is late. The latest we can see is [STATUS]. The new expected delivery is [DATE].
You can wait, or reply "cancel" and we will refund you in full today. We are sorry.

[NAME], [BRAND]
```

## 3. Arrived damaged or defective

```
Hi [FIRST NAME],

We are sorry about that. Please send a photo of the item and the packaging, with your order number. As soon as we have it, we will send a replacement or refund you, whichever you prefer. You do not need to send the item back.

[NAME], [BRAND]
```

## 4. Wrong item

```
Hi [FIRST NAME],

Thank you for telling us. Please send a photo of what you received and the packing slip if there is one. We will send the right item or refund you. We will reply with any return steps within one business day.

[NAME], [BRAND]
```

## 5. Return request

```
Hi [FIRST NAME],

You can return it within [X] days of delivery. Return shipping is [paid by you / paid by us]. Please do not send anything yet. We will reply with the return address and steps within one business day. Your refund goes to your original payment method within [5-10] business days after we receive the item.

[NAME], [BRAND]
```

## 6. Cancel before it ships

```
Hi [FIRST NAME],

We have asked to cancel order [ORDER NUMBER]. If it has not shipped, we will refund you in full within [5-10] business days. If it already shipped, we will send return instructions when it arrives.

[NAME], [BRAND]
```

## 7. Change address

```
Hi [FIRST NAME],

Please send the full new address. If the order has not shipped, we will update it. If it has shipped, we cannot change it, and we will tell you what we can do.

[NAME], [BRAND]
```

## 8. Tracking says delivered but I did not get it

```
Hi [FIRST NAME],

We are sorry. Please check around the delivery address, with neighbors and with anyone at home. Wait [1-2] business days in case of a scan error. If it still has not turned up, reply and we will open a claim with the carrier and send a replacement or refund.

[NAME], [BRAND]
```

## 9. Product question

```
Hi [FIRST NAME],

Thanks for asking. The supplier's specification says: [QUOTE FROM LISTING]. It does not say anything about [THE THING THEY ASKED]. We do not want to guess, so we cannot confirm that.

[NAME], [BRAND]
```

Rule: answer only from the supplier listing. Never add a safety, health or compatibility claim.

## 10. Customer mentions a chargeback

```
Hi [FIRST NAME],

We would like to fix this directly. Please tell us what went wrong with order [ORDER NUMBER]. If we can refund or replace it today, we will.

[NAME], [BRAND]
```
