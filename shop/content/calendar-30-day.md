## How to use a row

1. Pick a hook for the pillar from `hooks.md`.
2. Fill the matching script template from `scripts.md` using the product's claims log.
3. Generate the clip with the recipe in `ai-video-tool.md`. Check it against the fidelity checks. Retake if it fails.
4. Label it as AI-generated where the platform asks (`claims-checklist.md`).
5. Export without any watermark, then upload natively to each platform. Do not upload a file that still carries another app's watermark.
6. Post. Put the store link in your bio. Add a comment-keyword call to action if you set up the automation.

## Re-cut rule

A re-cut is a **new edit of your own clip**, not a second upload of the same file. Change the first 3 seconds (new hook text and a different opening frame), the caption and the on-screen text. If you cannot make it visibly different, skip the day rather than repost.

## Review days (7, 14, 21, 28)

1. Pull views, watch time, saves, shares, add-to-carts and orders by clip.
2. Mark the top 2 clips and the bottom 2. Write one sentence on why.
3. Apply the kill rules from the plan: pause a product past 8% refunds or complaints, pause a supplier after 3 late fulfilments.
4. Replace the weakest planned angle for next week with a variation of the strongest.
5. Paste the numbers to Claude for the weekly review.

## Not posting yet?

Do not start the calendar until the fidelity test has passed and the store has passed its test checkout. See `../README.md`.
