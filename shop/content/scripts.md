# Presenter-style scripts

Format: 10-15 seconds, one Seedance 2 clip, narrator voice-over plus on-screen text. No on-screen person says "I used this". The voice is a **narrator**, not a customer. Every claim comes from the claims log.

## Structure (15 seconds)

| Seconds | Beat | Job |
|---|---|---|
| 0-2 | Hook | Name the problem in one line of on-screen text (`hooks.md`) |
| 2-6 | Problem | Show the annoying moment, in the customer's words |
| 6-11 | Reveal and demo | Show the product doing the one thing the listing says it does |
| 11-14 | Listing proof | One real spec: material, size, capacity, included parts |
| 14-15 | CTA | "Link in bio" or "Comment LINK". Free U.S. shipping only if true. |

## Rules

1. Narrator, not customer. "This bed has a raised edge" is fine. "My dog loves this bed" is not.
2. One function per clip. If you need two, make two clips.
3. Show only what the listing supports. If the listing does not show it, the clip does not show it.
4. Hands near the product deform in AI video. Show the product alone, or a hand resting near it.
5. Voice-over under 35 words for 15 seconds.

## Template A - Problem

```
HOOK (0-2):      [H-xx with PROBLEM]
PROBLEM (2-6):   Show [ANNOYING MOMENT]. VO: "[Customer phrase]."
REVEAL (6-11):   Product appears in the same setting. VO: "[PRODUCT] is made to [LISTED FUNCTION]."
PROOF (11-14):   On-screen: "[LISTED SPEC]". VO: "[Same spec in words]."
CTA (14-15):     "Link in bio."
```

## Template B - Demo

```
HOOK (0-2):      "Watch what this does."
DEMO (2-11):     One continuous shot of [LISTED FUNCTION], slow camera push-in. VO narrates the single step.
PROOF (11-14):   On-screen: "[LISTED SPEC]".
CTA (14-15):     "Link in bio."
```

## Template C - Objection

```
HOOK (0-2):      "[OBJECTION as a question]?"
ANSWER (2-11):   Show the listed feature that answers it. VO: "[One honest sentence]."
PROOF (11-14):   On-screen: "[LISTED SPEC]".
CTA (14-15):     "Questions? Comment below."
```

## Template D - Use case

```
HOOK (0-2):      "For anyone who [AUDIENCE TRAIT]."
SCENES (2-11):   Two listed uses, two short scenes. VO: "[USE 1]. [USE 2]."
PROOF (11-14):   On-screen: "[LISTED SPEC]".
CTA (14-15):     "Link in bio."
```

## Template E - Comparison

```
HOOK (0-2):      "[OLD WAY] vs [PRODUCT]."
SPLIT (2-11):    Left: the old way and its annoyance. Right: [PRODUCT] doing [LISTED FUNCTION].
PROOF (11-14):   On-screen: "[LISTED SPEC]".
CTA (14-15):     "Link in bio."
```

## EXAMPLE (illustrative; depends on the real listing)

Product type: a raised-edge pet bed. The listing in this example says: bolster edges, plush fill, removable machine-washable cover, 30 x 20 inches.

```
HOOK (0-2):      On-screen: "Dog won't settle at night?"
PROBLEM (2-6):   A dog circles on a flat blanket. VO: "Flat beds give nothing to lean on."
REVEAL (6-11):   Same dog-size room, the raised-edge bed in frame. VO: "This one has raised bolster edges to curl into."
PROOF (11-14):   On-screen: "Removable cover. Machine washable." VO: "The cover comes off for the wash."
CTA (14-15):     "Link in bio."
```

Note what the example does **not** say: that it calms anxious dogs, reduces stress, or that any dog liked it. The listing does not support those claims.

## Seedance prompt for the example reveal

```
Image-to-video from the attached product photos. Keep the bed exactly as in the photos: same shape, color, stitching and proportions. Scene: a bright living-room corner, a medium dog-sized shadow on the floor, no dog touching the bed. Camera: slow push-in. Duration: 8 seconds. No text, no logos other than the product's own, no extra products. Natural light.
```
